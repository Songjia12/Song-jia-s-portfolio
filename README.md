# 宋祝蓓佳 · 个人主页

双击 index.html 即可离线打开，正文、图片、报告、证书均在本文件夹中。作品链接和飞书表格需要联网。

本地预览：在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765。

* index.html：主页

* report.html：完整报告，带可折叠目录和全部原始图表

* certificates.html：证书与研究成果

* data.js：六个项目，顺序和内容提取自简历

* assets/resume.pdf：原版简历

技能：design、ui-styling、ui-ux-pro-max。使用浅灰与克莱因蓝，并遵循键盘操作、移动端适配与减少动态效果设置。
所有资料均来自用户提供文件；未发布到公网。公开部署前请确认个人电话、邮箱及报告适宜公开。
